# 국민AI서비스혁신추진단 설계안

첨부 설계안을 바탕으로 제작한 12장 종이 리포트형 HTML 발표자료입니다.

## 사용법

- `←` `→` 또는 스페이스: 슬라이드 이동
- `F`: 전체화면
- `Home` / `End`: 처음 / 마지막 슬라이드

## 핵심 설계

- 다양한 도메인의 기관 AI 챔피언 영입
- 기관 챔피언과 활용 가능한 데이터의 동시 투입
- AI 챔피언 1명과 민간 개발자 1명의 실행 셀
- 제출과제 40개와 생활밀착형 발굴과제 50개의 통합 포트폴리오
- 문제 발굴부터 검증·확산·이관까지의 생명주기 운영
